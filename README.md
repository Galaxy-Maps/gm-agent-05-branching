# Branching

Generates optional side-quest branches off each curriculum Star.

Part of the [Galaxy Maps](https://github.com/Galaxy-Maps) modular skill stack — each role in the Galaxy Map creation pipeline lives in its own repo so it can be iterated on independently.

## Install

Clone into your Claude Code skills directory:

```bash
git clone https://github.com/Galaxy-Maps/gm-agent-05-branching.git ~/.claude/skills/gm-agent-05-branching
```
